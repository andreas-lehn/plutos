Platos bot notes
==================

This folder contains notes.
It is inspired by the Blue Book Note concept of Axel Schairer:
What ever is in your mind and worth noting should be writen down in a note.

File name follow a convention:

    PBN-nnn---file_name_with_underscores

Example:

    PBN-001---general_thoughts_about_a_trading_bot.md
